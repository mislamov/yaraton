# Яратон Пельнян

Статический каталог по [публичной форме производителя](https://docs.google.com/forms/d/e/1FAIpQLSfhEpVE2OAboDvlqyLiq9zHBH21oMfBPYNaQIJ7zUUQ2_YqEg/viewform).
HTML, CSS и JavaScript без серверной части и без сборки. Публичные файлы находятся в `public/`. Можно разместить на любом статическом хостинге, включая GitHub Pages, или запустить локально через HTTP.

## Возможности

- 43 товара с ценами за упаковку, весом, составом и локальными фотографиями из формы.
- Поиск по названию и составу, категории, корзина с количеством от 1 до 99.
- Корзина сохраняется в localStorage, её содержимое не отправляется на сервер.
- Отдельный расчёт доставки: 500 ₽ при сумме продуктов менее 2 000 ₽, бесплатно от 2 000 ₽.
- Копирование сообщения вида `Блины с курицей 1 Пельмени Царские 2` в порядке добавления, без суммы и служебного текста.
- Мобильная версия, клавиатурная навигация, резервный способ копирования.

## Запуск и проверки

```sh
npm ci
npm start
# http://127.0.0.1:4173
npx playwright install chromium
npm test
```

Проверки охватывают фотографии, корзину, расчёт бесплатной доставки на границе 2 000 ₽, сохранение, буфер обмена, поиск, обработку повреждённого хранилища и мобильный экран.

## Обновление каталога

Цены и составы — снимок формы от 14 ноября 2026 года; автоматической синхронизации в браузере нет. Редактируйте `public/products.json`, либо импортируйте заново:

```sh
python -m pip install -r scripts/requirements.txt
python scripts/import_catalog.py
```

Импортёр читает две страницы формы и скачивает фотографии. Для перехода ко второй странице он заполняет обязательные поля символом «—» и нажимает только «Далее»; форму не отправляет и заказ не оформляет. Общие фотографии разделов используются для соответствующих вариантов, как в исходной форме. После импорта проверьте данные и выполните тесты перед публикацией.

## Публикация

GitHub Actions проверяет сайт и публикует `public/` в GitHub Pages при push в `main`. В настройках репозитория Pages должен использовать GitHub Actions. Изменения каталога не требуют сервера или базы данных.
